# Racked

A clean, mobile-first workout logger. No accounts, no ads, no nonsense.

Pick a template (Bro Split, PPL, Booty Camp, etc.), log your sets, finish — get a summary you can throw to ChatGPT or Claude for analysis. Built as a PWA, wraps to Android via Trusted Web Activity for the Play Store.

## Templates included

1. **Bro Split** — Classic 5-day body part
2. **PPL** — Push / Pull / Legs
3. **Booty Camp** — Glute / lower emphasis
4. **Tris & Thighs** — Tone / recomp, arms + legs focus
5. **Big Three** — Squat / Bench / Deadlift
6. **The Gauntlet** — Circuit
7. **Nice Pair** — Supersets
8. **Open Bar** — Blank / custom

## Stack

- Vanilla HTML / CSS / JavaScript — no framework
- localStorage for everything (no backend, no accounts)
- Service worker for offline use
- Chart.js loaded from CDN for the analyze tab
- Wraps to Android via PWABuilder.com → TWA

## Files

- `index.html` — the app
- `manifest.json` — PWA install metadata
- `sw.js` — service worker, caches the shell for offline
- `icons/` — app icons (SVG source, PNG generated by PWABuilder)

## Run locally

Just open `index.html` in a browser. It's self-contained.

For PWA install testing on Android: serve from any HTTPS URL (GitHub Pages, Cloudflare Pages, etc.) and open in Chrome → Add to Home Screen.
